# Curated LBA2 game-flag (ListVarGame) knowledge, merged by `ScriptRoundTrip gameflags` with LBATrainer's quests.xml
# and the data mined from every retail scene script. Format, one flag per line:
#   id|symbol|kind|name|values|notes
# - symbol: COMMON.H constant, or empty.
# - kind: inventory, count, quest, flag, track, bits, decor, engine, unused.
# - name / values empty: inherit LBATrainer's. values "-" clears trainer values. values format  0=text;1=text
# - notes: free text, never contains a pipe.
# Scene numbers are SCENE.HQR numbers (entry - 1); "s27" = scene 27. Demo scenes are 193 and up.
#
# ---- inventory (0-39). TabInv slots; FOUND_OBJECT / STATE_INVENTORY / USE_INVENTORY take the slot number as the var. ----
